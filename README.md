# FreeShiamy（Android IME）

這是一個**碼表驅動的字根輸入法**鍵盤（Android `InputMethodService`）。你輸入「字根碼／字碼」後，候選字會顯示在鍵盤上方，並可用空白鍵與數字鍵快速選字。

## 資料來源
- **字根碼表**：由熱心網友手動整理／輸入後提供（收錄於 `app/src/main/assets/freeshiamy.cin`）。
- **注音對照表**：來源為教育部公開資料（收錄於 `app/src/main/assets/cht_spells.cin`），用於「同音字」反查功能。
- **符號、Emoji 與顏文字**：字符資料整理自 [肥肥注音](https://github.com/wdzeng/google-fatty-zhuin-ime/tree/af24a6faa849da013b01a6b0debae52948d19424)，來源版本、完整目錄與本專案的差異見 [資料文件](doc/google-zhuyin-symbols.md)。

## 安裝與使用
1. 從 GitHub **Releases** 下載 APK 並安裝（或從 **Actions** 的 artifact 下載）。
2. 到 Android 系統設定啟用此輸入法（語言與輸入法／螢幕鍵盤／管理鍵盤），並在任一輸入框切換鍵盤使用。
3. App 內提供 **Test Panel**，可用來快速測試鍵盤行為與候選選字。

### 基本操作（精簡）
- 輸入字根碼後：候選列會依相關度顯示；點選候選即可送出並進入下一輪。
- **空白鍵／數字鍵**：在「有符合候選」時用於快速選字；在「沒有任何累積字元」時，空白鍵會直接送出空白。
- **符號鍵盤上的數字與符號**：原碼欄為空時直接送出；有待送原碼時按原文接續，不用作選字索引。英文鎖定時直接送出。
- **刪除鍵**：若按下時上方暫存欄有內容，長按只會刪到暫存欄清空為止；需放開再按才會刪輸入框內既有文字。
- **提示字根**（設定預設開）：上屏後會在候選列右側顯示該字的最短字碼（含反查選字）。
- **反查同音字**：用單引號前綴（`'`）進入反查；用刪除鍵可取消反查並回到一般狀態（詳細規格見 `freeshiamy.md`）。
- **符號／Emoji／顏文字**：`?123` 進符號表，長按模式鍵或字母頁逗號進 Emoji；左上選擇符號、Emoji 或顏文字，再選分類。左右平滑滑動換頁，可跨分類；長按有小點標記的項目可選變體。底列為 ABC、逗號、50% 寬空白、句點及 Enter，按 `ABC` 回字母鍵盤，收起／切換鍵盤由工具列操作。
- **密碼/隱私欄位**（設定預設開）：遇到密碼欄位會自動切換到其他輸入法（或顯示輸入法選擇器）；可另外設定是否把「不允許個人化學習」也視為隱私欄位。
- **鍵盤排列**：採用固定的梯狀 QWERTY，q／a／z 三列起點依序為 0／半格／一格；Shift 佔一格，右側刪除鍵佔兩格。底列為逗號、50% 寬空白及句點，單引號收進 z 長按選單。數字列可開關。符號表底列與字母頁對齊，收起／切換鍵盤集中於工具列。
- **鍵盤外觀與回饋**：可調高度百分比與按鍵觸覺回饋；按下文字鍵時顯示放大預覽，高度調整不會拉伸字體。
- **長按字母**：依實機 Google 注音英文模式對照，顯示大寫、隱藏符號與重音／聲調字母；選項多時分列顯示，滑動選擇、放開送出。Q–P 對應 1–0，z 另保留「、」；句點長按提供常用標點與文字表情，逗號長按開啟 Emoji。取消或收起不送字。
- **工具列**：閒置時可開設定、切換輸入法、收起鍵盤或鎖定英文；輸入字碼時，可用九宮格圖示開工具、左箭頭返回候選列。英文鎖定會先按原文送出待輸入字碼，再直接輸出英文、數字與標點；選取底色表示開啟，再按回到字根輸入。
- **Shift／Caps Lock**：點一下只讓下一個字母大寫，連按兩下鎖定持續大寫，箭頭底線亮起；再按一下解除。此狀態會保留至符號頁返回，候選查詢仍不分大小寫。

Google 注音實測對照、肥肥注音完整符號／Emoji／顏文字資料與翻頁規則見 [鍵盤參考資料](doc/google-zhuyin-symbols.md)，文件附可直接讀取的完整 JSON。實作範圍見 [鍵盤計畫](plan/gboard-symbols-english-lock-plan.md)，開源來源評估見 [OSS 研究](plan/gboard-open-source-scout.md)。

符號表採七類 542 個位置（含補充符號）；Emoji 為八類 1,404 個主選項與 880 個長按位置（Android 6–7.0 使用舊版 1,357／504）；顏文字五類共 90 項。系統字型決定 Emoji 的繪製支援。App 只打包約 39 KB 的按頁文字資料與索引，按需建立目前與鄰頁，離開時釋放。更新資料後執行 `python3 scripts/generate_symbol_catalog.py`，以 `--check` 核對完整資料與輸出。

## 釋出與下載（GitHub Actions）
本專案使用 GitHub Actions 自動編譯 **release APK**：
- **觸發方式**：推送 Git tag（符合 `v*`，例如 `v1.0.0`）或手動 `workflow_dispatch`。
- **如何打 tag**
  ```bash
  git tag -a v1.0.0 -m "v1.0.0"
  git push origin v1.0.0
  ```
- **下載位置**
  - GitHub **Releases**：會附加 `freeshiamy-<tag>.apk`
  - GitHub **Actions**：對應的 workflow run 內可下載 artifact

## 簽章（重要說明）
為了讓 CI 能直接產出可安裝的 APK，repo 內包含一份 **公開的 release keystore**（`keystore/freeshiamy-release.jks`）。這個簽章**不應被視為信任來源**（任何人都能使用相同 keystore 產出相同簽章的 APK）。

如果你在意可驗證的信任鏈，請自行從原始碼編譯並改用你信任的簽章：
- 產生 keystore（示例）：`keytool -genkeypair ...`
- 在本機修改 `keystore/release.properties` 指向你的 keystore 後再執行：
  ```bash
  ./gradlew :app:assembleRelease
  ```
